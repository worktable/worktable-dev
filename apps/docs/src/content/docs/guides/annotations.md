---
title: Annotations
description: Attach feedback to content, request revisions, and track responses.
---

Annotations attach feedback to a whole document, a block, or a passage. People
and agents can comment, reply, and resolve them.

## Leave feedback

Select content in a document and add an annotation. Say what should change:

```text
This total excludes equipment rental. Recalculate it using the estimate
in the project brief and show the assumptions.
```

For broader conversation, use a [thread](/guides/threads/).

## Ask an agent

Ask a connected agent to handle the document's open annotations. It can edit
the document, reply with what changed, resolve the annotation, or ask you a
question.

Annotations don't start an agent on their own. The optional
[annotation skill](/agents/annotations-protocol/) gives skill-capable clients a
workflow.

## After edits

Annotations keep their quoted text. If the passage has changed, check the quote
and discussion to see whether the request still applies.

## Resolve a thread

Resolve an annotation when it's handled or no longer applies, with a short reply
saying why. Leave open questions unresolved so people can find them.
